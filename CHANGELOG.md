# Changelog

All notable changes are documented here. DeepPeak follows Semantic Versioning.

## Unreleased

### Added

- Reproducible scientific benchmark datasets, metrics, calibration, and uncertainty helpers.
- Separate fast and ML test lanes with an 80% coverage target.
- Task-oriented guides, model-card guidance, API stability policy, and maintained tutorial.

### Changed

- TensorFlow is optional and neural APIs load lazily.
- Public analyzer names and configuration objects use the canonical API introduced in 0.2.

### Removed

- Compatibility adapters, legacy analyzer aliases, combined dilution-series arguments, and legacy notebooks.

## 0.2.0

- Established Packlab-style automated versioning, tagging, and release workflows.
