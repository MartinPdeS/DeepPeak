Webinar showcase
================

The repository includes the maintained webinar deck, its editable Keynote
source, and the scripts and image assets used by the live demonstrations.

* ``showcase/webinar/presentation.key`` — presentation source
* ``showcase/webinar/build_presentation.py`` — reproducible supporting assets
* ``showcase/webinar/README.md`` — build and download instructions

The deck uses a section-specific palette based on DeepPeak teal (``#006D77``),
problem coral (``#EF8354``), method dark teal (``#004854``), evidence amber
(``#B56B12``), and ink (``#102A33``). The documentation uses the same colors
for headings, admonitions, and code callouts.
